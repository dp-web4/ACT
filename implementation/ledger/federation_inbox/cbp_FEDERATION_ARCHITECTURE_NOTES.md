## 1. Security & Privacy Architecture

### Public vs Private Repositories

**PUBLIC** (Open disclosure):
- ACT repository - blockchain implementation
- Web4 repository - protocol specifications
- HRM repository - SAGE development

**PRIVATE** (Controlled disclosure):
- `/private-context/federation/` - security-sensitive communications
- Business not ready for public disclosure
- Internal deliberations and experiments
- Security vulnerability discussions before patches

### Security Queen Responsibilities

Each society's Security Queen MUST:
1. Create and maintain `/private-context/federation/[society_name]/` directory
2. Review all commits before pushing to public repos
3. Ensure no sensitive data leaks to public repositories
4. Coordinate security discussions in private-context
5. Maintain separation between public work and private deliberation
